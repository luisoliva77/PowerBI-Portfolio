Dashboard de Gestão de Pessoas

Projeto de análise de Recursos Humanos desenvolvido no Power BI com foco em indicadores estratégicos de colaboradores, turnover, distribuição de funcionários e análise hierárquica organizacional.

Objetivo do Projeto

O objetivo deste dashboard é fornecer uma visão analítica sobre os dados de Recursos Humanos da empresa, auxiliando no acompanhamento de indicadores importantes relacionados aos colaboradores e à estrutura organizacional.

Com este painel é possível analisar:

Quantidade de funcionários ativos
Taxa de turnover
Distribuição entre homens e mulheres
Funcionários por cidade
Motivos de faltas
Estrutura hierárquica da empresa
Distribuição de dependentes por tipo

Ferramentas Utilizadas
Power BI
SQL
Excel / CSV

Recursos Interativos

O dashboard conta com filtros dinâmicos que permitem segmentar as análises de forma prática e rápida.

Exemplo de filtros:

Departamento
Cargo
Cidade

Principais Insights
A distribuição entre homens e mulheres está equilibrada.
O turnover da empresa está relativamente elevado.
Algumas cidades concentram maior quantidade de colaboradores.
O setor de Dados e BI possui forte participação na estrutura organizacional.
Os principais motivos de falta estão relacionados a atrasos e consultas médicas.
