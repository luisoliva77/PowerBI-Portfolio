# Dashboard de Vendas

Projeto de análise de vendas desenvolvido no Power BI com foco em visualização de indicadores estratégicos, faturamento, volume de pedidos e desempenho de produtos e lojas.

Este dashboard foi criado com o objetivo de transformar dados de vendas em informações visuais claras e objetivas, permitindo uma análise rápida do desempenho comercial da empresa.

# O painel possibilita acompanhar:

Receita total
Quantidade de clientes
Quantidade de pedidos
Ticket médio
Produtos com maior faturamento
Receita por período
Volume vendido por loja
Comparação entre vendas presenciais e online

# Principais Insights
As vendas presenciais representam a maior parte da receita.
Alguns produtos concentram grande percentual do faturamento total.
Há estabilidade no volume de pedidos ao longo dos meses.
Determinadas lojas possuem desempenho superior em quantidade vendida.
