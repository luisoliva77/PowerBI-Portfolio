# Dashboard Airbnb Nova York

Dashboard desenvolvido para analisar o mercado de hospedagens do Airbnb em Nova York, transformando os dados da base em indicadores e insights visuais que facilitam a compreensão de preços, imóveis, localização e características dos anfitriões.

O projeto foi desenvolvido com foco em análise exploratória, visualização de dados e geração de insights, permitindo que o usuário navegue por diferentes perspectivas do mercado e utilize filtros para aprofundar a análise.

## Objetivo

O principal objetivo do dashboard é permitir uma visão geral do mercado de hospedagens do Airbnb em Nova York e responder perguntas relevantes sobre:

Preços das hospedagens;
Distribuição dos anúncios;
Localização dos imóveis;
Disponibilidade;
Tipos de imóveis;
Anfitriões;
Avaliações;
Diferenças entre as regiões de Nova York.

### ❓ Perguntas que o Dashboard Ajuda a Responder
```text
💰 Preços
Qual é o preço médio das hospedagens?
Quais regiões apresentam os maiores preços médios?
Como os preços variam entre as regiões de Nova York?
Quais regiões possuem hospedagens mais acessíveis?

🏠 Imóveis
Quantos anúncios existem na base?
Quais são os tipos de imóveis mais comuns?
Qual tipo de imóvel possui maior participação nos anúncios?
Como os anúncios estão distribuídos entre os diferentes tipos de acomodação?

📍 Localização
Em quais regiões existe maior concentração de anúncios?
Como os anúncios estão distribuídos geograficamente?
Quais bairros possuem maior quantidade de hospedagens?
Existe concentração de anúncios em determinadas áreas de Nova York?

👤 Anfitriões
Quais anfitriões possuem maior quantidade de anúncios?
Quem são os anfitriões com maior presença na plataforma?
Como os anúncios estão distribuídos entre os anfitriões?

⭐ Avaliações e disponibilidade
Qual é a média de avaliações dos anúncios?
Como está a disponibilidade média das hospedagens?
Existem diferenças de disponibilidade entre as regiões?
Quais regiões apresentam maior disponibilidade média?
````

# 📌 Principais Insights

### A página inicial apresenta uma visão geral do mercado através de indicadores e gráficos.

# Entre os principais insights identificados:
```text
### 💰 Manhattan apresenta o maior preço médio

Entre as regiões analisadas, Manhattan apresenta o maior preço médio, enquanto o Bronx apresenta o menor valor médio.

Esse indicador permite observar uma diferença significativa no comportamento dos preços entre as regiões.

### 📅 Diferença na disponibilidade

A disponibilidade média também apresenta diferenças relevantes entre as regiões.

Staten Island possui a maior disponibilidade média, enquanto Brooklyn apresenta a menor disponibilidade entre as regiões exibidas.

### 📍 Concentração dos anúncios

O mapa demonstra uma forte concentração de anúncios na região de Nova York, permitindo visualizar como os imóveis estão distribuídos geograficamente.

Essa visualização facilita a identificação de áreas com maior concentração de hospedagens.

### 👤 Concentração de anúncios por anfitrião

O ranking de anfitriões permite identificar quais possuem maior quantidade de anúncios na plataforma.

Na visão apresentada, Michael e David aparecem entre os anfitriões com maior quantidade de anúncios, seguidos por outros anfitriões com volumes menores.

### 🏠 Distribuição dos tipos de imóvel

O gráfico de distribuição demonstra que determinados tipos de acomodação representam uma parcela significativamente maior dos anúncios, enquanto outros possuem uma participação muito menor.

Essa visualização ajuda a compreender o perfil predominante das hospedagens disponíveis.
```
## 🧭 Sistema de Navegação

O dashboard possui um sistema de navegação lateral que permite acessar diferentes páginas de análise.

As opções disponíveis são:
```text
Página Inicial
│
├── Preços
├── Imóveis
├── Localização
└── Anfitriões
```
Cada tópico direciona o usuário para uma página específica com indicadores, gráficos e insights relacionados ao assunto selecionado.

# Sistema de Filtros

O dashboard também possui um sistema de filtros interativo, permitindo que o usuário personalize a análise de acordo com os dados que deseja visualizar.

O botão "Filtrar" permite acessar os filtros disponíveis e modificar a visão apresentada no dashboard.

Dessa forma, o usuário pode:
```text
Selecionar diferentes regiões;
Analisar subconjuntos específicos dos dados;
Comparar informações de acordo com os critérios selecionados;
Identificar padrões específicos;
Aprofundar os insights apresentados nos gráficos.
```
Os indicadores e visualizações são atualizados de acordo com os filtros aplicados, tornando o dashboard interativo e exploratório.

## Conclusão

O dashboard transforma uma grande quantidade de dados sobre hospedagens do Airbnb em uma interface interativa, visual e orientada à análise, permitindo identificar padrões relacionados a preços, imóveis, localização, anfitriões, disponibilidade e avaliações.

A utilização de navegação entre páginas e filtros interativos permite que o usuário explore diferentes perspectivas dos dados e encontre insights de acordo com suas necessidades de análise.
